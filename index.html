      How the values are set

      A unit from the summon is worth what it costs to pull with the 2x luck pass, at 900 tokens for 10 summons. Units you cannot summon are priced from how many copies exist: the fewer exist, the more they are worth. A few more copies do not move a value: it only changes when the count goes up or down by half. The number on each picture is how many exist right now.

      Units and gloves that nobody owns yet show O/C, which means owner's choice: there is no real value until copies exist, so whoever gets one first sets the price. Their trend and demand show N/A. Gloves are priced from what they cost in slaps, with 1 slap counted as 300 tokens. One slap match pays about 330 slaps and one good normal match about 100K tokens, so a glove costs the same number of matches either way. A crate is worth the average of what it drops.

      New update 2 units start at up to 3 times their summon cost and come down as more copies show up, until they match the older unit of the same rarity. The trend compares each value with the last count: rising is up 10% or more, ultra rising is up 50% or more, dropping is down 10% or more. Demand is how much players want it in trades.

      Tokens count 1 for 1 in the calculator. A trade within 10% is called fair. The owner can also set a value by hand when the count gets it wrong.

      The gem value under each price counts 1 gem as 5,000 tokens, which is what the hardest match pays: 75,000 tokens and 15 gems. Gem banner units are worth what they cost to pull in gems with the 2x luck pass, and like update 2 units they start at up to 3 times that while few exist.
